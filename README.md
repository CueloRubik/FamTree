# FamTree

Archivo genealógico interactivo. El código, los datos públicos revisados y la documentación técnica están en la rama [Development](https://github.com/CueloRubik/FamTree/tree/Development).

La aplicación se publicará con GitHub Pages desde Development. Los registros de personas vivas o de estado desconocido deben permanecer en archivos privados locales, nunca en el repositorio público. No subir archivos privados, credenciales ni exportaciones completas de FamilySearch.
