Cómo usar FamTree

1. Proyectos: crea un árbol nuevo o abre un archivo existente.

2. Añadir persona: escribe el nombre. Las demás fechas y fuentes son opcionales.

3. Selecciona un círculo: abre su ficha. Usa Añadir familiar para crear padres, hijos, parejas o hermanos.

4. Organiza: arrastra el fondo para navegar, arrastra círculos para moverlos y usa la rueda para acercarte. Ordenar restablece las posiciones.

5. Guarda: el proyecto local se guarda solo; Guardar crea una copia de archivo en la web o escribe el documento en la aplicación de escritorio.

Los proyectos se guardan en este dispositivo. Exporta archivos .ftree para conservar copias o abrirlos en otra computadora. Los archivos no están cifrados.

FamilySearch se abre en otra pestaña y puede pedir iniciar sesión. No existe sincronización directa con FamilySearch.
